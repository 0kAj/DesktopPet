DesktopPet is a desktop pet application that I developed using [WPF](https://learn.microsoft.com/dotnet/desktop/wpf/overview/) and [C#](https://learn.microsoft.com/dotnet/csharp/tour-of-csharp/overview).  
This project is my final submission for the course **“Praktische Informatik”** at **Hochschule Hamm-Lippstadt (HSHL)**.

## 📌 Project Description
With DesktopPet, I created a customizable and interactive virtual pet that lives directly on the desktop.  
The pet can be fed, reacts to mouse input, moves freely around the screen, and allows the user to play mini games.  
Currently included mini games are **Food Collector** and **Pet Jump**.

## 🐭 Features
- 🎮 Play mini games such as **Food Collector** and **Pet Jump**
- 🍎 Feed the pet using different food items
- 🖱️ Interact with the pet through mouse movement and clicks
- 🎨 Customize the pet’s color appearance

## 🕹️ Controls
Outside of mini games, the pet can be moved freely across the desktop using drag and drop.

During mini games, the pet follows the mouse cursor and moves horizontally along the X-axis.
Pressing the Space key triggers the jump action.
The Escape key opens the pause menu.
